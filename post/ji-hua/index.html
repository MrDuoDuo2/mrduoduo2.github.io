每日食谱规划

个人情况：183cm / 83kg，力量训练，瘦胖子，新手训练期
目标：每日蛋白质 133‑149g；热量适度盈余增肌，不疯狂堆脂肪；尽量靠天然食物，可选择是否加蛋白粉；肌酸每日5g固定吃。

区分：生重/熟重；训练日、休息日两套，晚餐允许外卖（小炒/冒菜/面条）

🥚早餐（固定，家里解决）

  • 茶叶蛋 3个（去壳）
  • 纯牛奶 250ml
  • 可选加餐：小馒头1个 / 香蕉1根（碳水，训练日前建议吃）

蛋白：3×6 +8 = 26g

🍱午餐（自制便当，核心补蛋白）

  • 生鸡胸肉：220g（水煮/少油煎，煮熟约155g）≈46g蛋白
  • 西兰花（生）：280g，焯水
  • 熟米饭：200g（一平碗多，必须吃，力量供能）

午餐蛋白≈46g

便当小技巧：鸡胸提前腌盐+黑胡椒+少量生抽；西兰花分开装，避免泡烂。

🍽️晚餐（外卖，二选一，优先A/B，少吃面条）

A｜小炒档（优先选）

选：青椒肉丝、蒜香牛肉、香煎鸡腿等；备注：少油，多加肉，少酱汁
熟肉类分量控制：130‑150g熟肉
搭配：正常一份米饭150‑180g熟重，配素菜一份
蛋白≈34‑38g

B｜冒菜档（次选）

多选：牛肉、鸡胸、瘦肉片；少丸子、少加工货，多绿叶菜；少红油
主食：米饭150‑180g
蛋白≈32‑40g

C｜面条（尽量少当晚餐，肉太少）

牛肉面/杂酱面，额外加一份卤牛肉，主食吃面，再单点一份烫青菜
蛋白≈26‑30g

全天蛋白核算

早餐26g + 午餐46g + 晚餐取中间值36g = 108g蛋白
👉距离目标133‑149g，缺口：25‑41g

两种方案（你二选一）

方案①：不喝蛋白粉（硬靠食物）

在上面基础上，二选一执行：

  1. 训练日下午加餐：水煮蛋2个（+12g蛋白）+ 无糖酸奶一杯（+8g蛋白）
    全天蛋白来到 108+20 = 128g，接近目标下限。

缺点：一天吃5个鸡蛋，有些人肠胃腻、吃撑。

方案②：少量分离乳清蛋白粉（更轻松，推荐）

可以按你想法：0‑2个月尽量食物，实在吃不下再喝；或者直接训练日喝1勺。

  • 训练日：训练后1勺分离乳清（25‑27g蛋白）
    总蛋白：108+26 = 134g，刚好踩进目标区间。
  • 休息日：不喝蛋白粉，靠三餐即可。

补剂固定：肌酸5g，每天都吃，训练/休息都要，温水冲服，和吃饭无关。

📅训练日 vs 休息日完整版本

🔹训练日（力量训练当天）

早餐：3茶叶蛋 +250ml纯牛奶 +香蕉（可选）
午餐便当：生鸡胸220g +西兰花280g +熟米饭200g
训练前：可以吃一小块面包/半根香蕉，防止训练乏力
训练后：1勺分离乳清（可选，看你是否执行补剂）
晚餐：小炒/冒菜，足量肉+米饭

🔹休息日（不练）

早餐：3茶叶蛋 +250ml纯牛奶
午餐便当不变（鸡胸+西兰花+米饭）
晚餐：小炒/冒菜，肉量不变，不喝蛋白粉

休息日碳水不用猛减，适度吃，帮助恢复肌肉。

⚠️对你瘦胖子的几条关键红线

  1. 拒绝增肌粉，碳水全部来自米饭、红薯、面条正餐，不从粉获取。
  2. 午餐不要只吃鸡胸西兰花不吃米饭，碳水不足力量上不去，新手期进步会被限制。
  3. 晚餐尽量避开纯面条，肉量普遍严重不足。
  4. 油脂不要极端压低，小炒、冒菜正常油脂，不要天天水煮到底，激素需要脂肪。
  5. 不要疯狂多吃，温和热量盈余，不是暴饮暴食，防止堆内脏脂肪。

简单速记

  • 生鸡胸220g，午餐的灵魂；
  • 肌酸天天5g；
  • 训练日蛋白缺口大，要么加鸡蛋酸奶，要么1勺分离乳清；休息日不喝粉。
